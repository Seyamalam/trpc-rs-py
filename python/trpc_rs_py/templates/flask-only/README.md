# {{name}}

Generated by `trpc-py init --template flask-only` — a Flask backend serving a
tRPC router with end-to-end TypeScript types for the official `@trpc/client`,
plus a REST + OpenAPI surface, all through the WSGI adapter.

## Layout

- `server.py` — Flask app: tRPC under `/trpc` (`mount_wsgi`), REST + OpenAPI
  under `/api` (`wsgi_from_asgi` + `mount_rest`), both mounted with
  `werkzeug.middleware.dispatcher.DispatcherMiddleware`.
- `app-router.d.ts` — the generated router type your TypeScript app imports.

## Run

```bash
pip install trpc-rs-py flask
python server.py
```

## Live type sync

While you edit Python, regenerate `app-router.d.ts` on every save:

```bash
trpc-py dev --app server:router --out app-router.d.ts
```

## Call it

```ts
import { createTRPCClient, httpBatchLink } from "@trpc/client";
import type { AppRouter } from "./app-router";

const client = createTRPCClient<AppRouter>({
  links: [httpBatchLink({ url: "http://127.0.0.1:8000/trpc" })],
});

await client.greeting.query({ name: "world" });
await client.create_user.mutate({ name: "Ada" });
```

## WSGI streaming notes

SSE subscriptions stream through WSGI, but each open stream holds one worker
thread and disconnects are noticed on write — `server.py` sets
`sse_ping_interval=5.0` so dead clients are reaped quickly. High-concurrency
subscription workloads belong on an ASGI adapter instead.
