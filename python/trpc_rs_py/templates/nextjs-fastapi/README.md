# {{name}}

Generated by `trpc-py init` — a Next.js + FastAPI starter where a TypeScript
frontend calls Python procedures through the official `@trpc/client` with
end-to-end types.

## Layout

- `server.py` — FastAPI app: tRPC under `/trpc`, REST + OpenAPI under `/api`
  (`/api/openapi.json`, `/api/docs`).
- `web/` — Next.js app; `web/app-router.d.ts` is the generated router type.

## Run

```bash
# Python backend (port 8000)
pip install trpc-rs-py fastapi uvicorn
uvicorn server:app --reload

# Live type sync — regenerates web/app-router.d.ts on every Python save
trpc-py dev --app server:router --out web/app-router.d.ts

# Frontend (port 3000)
cd web && npm install && npm run dev
```

Open http://localhost:3000 — the greeting comes from Python via tRPC. The same
procedure is also a REST endpoint: `curl http://localhost:8000/api/greeting/world`.
