# {{name}}

Generated by `trpc-py init --template fastapi-only` — a FastAPI backend
serving a tRPC router with end-to-end TypeScript types for the official
`@trpc/client`, plus a REST + OpenAPI surface.

## Layout

- `server.py` — FastAPI app: tRPC under `/trpc`, REST + OpenAPI under `/api`
  (`/api/openapi.json`, `/api/docs`).
- `app-router.d.ts` — the generated router type your TypeScript app imports.

## Run

```bash
pip install trpc-rs-py fastapi uvicorn
uvicorn server:app --reload
```

## Live type sync

While you edit Python, regenerate `app-router.d.ts` on every save:

```bash
trpc-py dev --app server:router --out app-router.d.ts \
    --server "server:app"
```

## Call it

```ts
import { createTRPCClient, httpBatchLink } from "@trpc/client";
import type { AppRouter } from "./app-router";

const client = createTRPCClient<AppRouter>({
  links: [httpBatchLink({ url: "http://127.0.0.1:8000/trpc" })],
});

await client.greeting.query({ name: "world" });
await client.create_user.mutate({ name: "Ada" });
for await (const n of client.ticks.subscribe()) console.log(n);
```

The `greeting` procedure is also a REST endpoint:
`curl http://127.0.0.1:8000/api/greeting/world`, and the OpenAPI document is
at `http://127.0.0.1:8000/api/openapi.json` (Swagger UI at `/api/docs`).
