## Code generation

Deterministic generators — all raise `TypeError` rather than emit `any`:

* `generate_types(router)` → `AppRouter` `.d.ts` for the official client
* `generate_zod(router)` → zod v4 input schemas
* `generate_python_client(router)` → `AppRouterClient` module
* `generate_openapi`/`merge_openapi` → OpenAPI 3.1 document

*Generated from docstrings — see [`trpc_rs_py.codegen`](https://github.com/Seyamalam/trpc-rs-py/blob/main/python/trpc_rs_py/codegen.py).**Generated from docstrings — see [`trpc_rs_py.zodgen`](https://github.com/Seyamalam/trpc-rs-py/blob/main/python/trpc_rs_py/zodgen.py).**Generated from docstrings — see [`trpc_rs_py.pyclient`](https://github.com/Seyamalam/trpc-rs-py/blob/main/python/trpc_rs_py/pyclient.py).*
